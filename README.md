# Linkin World website

Next.js 15 (App Router) + TypeScript + Tailwind CSS v4, a React Three Fiber globe in the hero, and GSAP ScrollTrigger for motion.

## Run it

```bash
npm install
cp .env.example .env.local   # optional in dev
npm run dev                  # http://localhost:3000
npm run build && npm start   # production check
npm run typecheck
```

## Pages

| Route | What it is |
| --- | --- |
| `/` | Hero with the 3D globe, problem-led accordion, results, selected work, process, contact |
| `/services` | All services plus ways to work with us |
| `/services/[slug]` | 4 service pages: scope, outcome, tools, related work (static) |
| `/work` | All case studies |
| `/work/[slug]` | 5 case studies with counting metrics (static) |
| `/about` | Who we are, why us, process, platforms, team |
| `/contact` | Form, what to expect, direct contacts |
| `/privacy` | Privacy notice (needs client/legal review) |
| `sitemap.xml`, `robots.txt`, OG image | generated by Next |

## Structure

```
app/                     routes above, layout (header/footer), template.tsx (page transition)
  api/contact/route.ts   contact form handler (zod, honeypot, Resend)
components/
  hero.tsx, globe/       home hero and the R3F globe
  rings.tsx              small 3D linked rings used in page headers
  page-hero.tsx          inner-page header with title reveal
  site-header.tsx        sticky header, active links, animated mobile menu
  problems, platforms, results, process, team, contact, contact-form, case-card, count-up, cta-band
lib/
  content.ts   site copy (nav, why us, process, team, platforms)
  services.ts  service pages
  work.ts      case studies
  gsap.ts, hooks.ts
```

To add a service or case study, add an entry to `lib/services.ts` or `lib/work.ts`; the page, sitemap and links pick it up.

## Motion

- Hero: headline line reveal, globe scales in, side notes slide in (one timeline).
- Globe: drag to spin with inertia, pointer parallax, slow auto-rotation, arcs drawn out of Islamabad, scroll scrubs extra rotation and lift.
- Problems: accordion height animated with GSAP.
- Platforms sentence lights up word by word on scroll.
- Results: count-up and line grow once in view; pointer 3D tilt.
- Process line and step dots fill with the scroll; team photo settles with scroll and tilts on hover.
- Everything is wrapped in `gsap.matchMedia("(prefers-reduced-motion: no-preference)")`; with reduced motion the page is static and complete. The globe stops rendering when off screen.

## Contact form

`POST /api/contact` validates with zod and sends through [Resend](https://resend.com).
Set on Vercel/Netlify:

| Variable | Example |
| --- | --- |
| `RESEND_API_KEY` | `re_...` |
| `CONTACT_TO` | `contact@linkinworldtech.com` |
| `CONTACT_FROM` | `Linkin World website <website@linkinworldtech.com>` (verified domain) |

Without these, dev logs submissions to the server console; production returns 503 so nothing is silently lost.

## Deploy

Vercel: import the repo, framework preset Next.js, add the env vars above. Netlify works with its Next.js runtime.
